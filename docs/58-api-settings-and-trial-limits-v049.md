# v0.49 · 自备API、使用引导与试用保护

2026-11-06。用户要求继续开发，并明确：腾讯云由用户之后部署，本轮不用部署；比赛默认继续使用提供者密钥，也要给用户预留自己的API入口与引导。

## 使用方式

首页/工具页右上角“API设置”，或对话窗口右上角同名入口，均可打开同一套设置。默认“比赛提供的接口”，无需登录、无需填Key即可提问。进入“第一次使用”页签可看提问、来源、工具应用的三步说明；对话空态也有简短引导，不弹强制向导。

需要自备时展开“想用自己的API”，填DeepSeek密钥和模型，点击“测试并使用”。服务器通过官方`GET /models`核对密钥与模型，再启用临时会话。测试不是余额、完整工具调用或图像能力验收；聊天仍实际走本站计划和白名单工具。图像元数据明确不支持图片的模型会在发送前提示，且不扣识图次数。

第一版只支持官方DeepSeek地址，服务地址只读；没有实现任意OpenAI兼容中转站或多服务商。该选择防止用户输入内网地址，把本站变成任意代理。默认比赛接口私有配置保持；用户接口失败不覆盖原配置，可显式切回比赛接口。

用户密钥仅在服务端内存中保留约一小时，定时清理；不写进localStorage、浏览器草稿、账号、SQLite或作品包。浏览器只持有HttpOnly随机会话Cookie；设置成功及关闭窗口会清空输入。会话绑定当前游客/账号，切换账号、过期或服务重启后不得沿用；只要会话标记仍在，就明确显示失效，需重新连接或显式切回比赛接口。用于显示失效的随机Cookie可保留一天，不含密钥；清除Cookie或标记到期后回到默认比赛模式。云端运行后，维护者服务器会接收用户主动提交的密钥，这一数据流已在表单说明。

接口：同源`GET/POST/DELETE /api/v1/ai/settings`。POST请求最多4096字节，官方验证10秒、返回正文最多64KB；同时最多2个连接测试，每身份5次/分钟、全站20次/分钟。设置接口返回模式、模型、可用状态、过期时间，永不返回密钥。最多50个临时接口会话。

## 试用次数

|范围|提问/天|识图/天|
|---|---:|---:|
|游客浏览器|20|3|
|登录账号|40|6|
|同一网络|60|10|
|全站|100|20|

每类请求的网络分钟上限15；原对话12/分钟、图像6/分钟等全站短期保护保留。对话最多2路、图像1路，各身份各类仅1路；租约存入SQLite，防止同库的多个服务实例绕过并发。请求开始调用模型时计一次，取消/失败不返还；格式错误、未配置接口、队列/额度拒绝、明确不支持图像等不计次。计数是请求尝试，不是Token、账单或API余额。自备接口仍受站点资源保护，不提供无限调用。

`GET /api/v1/usage`只返回当前身份类别、本人计数及恢复时间，不暴露账号ID、IP、其他人的使用量或密钥。北京时间每天零点恢复。SQLite保存签名密钥、不可读身份/网络标识、次数与短租约，不保存问题、回复或图片。旧计数约三天内清理；没有新请求时不会后台不断写库。计数库与原账号库均在工程外的私有目录。

游客签名Cookie、账号真实会话、网络HMAC计数和全站上限分别发挥作用。清Cookie/新建账号不能突破当前网络和全站上限，但这不是完整反攻击平台；网络代理、多出口、公共NAT误限仍需真实部署校准。网络地址不以明文存库；默认忽略转发IP头，仅显式配置loopback且直连来自回环代理时才读取单个合法`X-Real-IP`。不信任任意`X-Forwarded-For`。

## 本轮验证与限制

自动检查174项（原160 + 14项）：签名游客、账号隔离/退出、持久重启、北京时间零点、独立实例共享配额/租约、可信代理、额度拒绝/Retry-After、上游失败、流式断开释放、不泄漏密钥、跨身份/过期自备接口、非法地址/模型/来源、文本模型拒图和客户端计数格式。

独立本机HTTP真实验证：使用现有提供者配置临时测试自备模式（不复制实际Key到源码或证据），官方模型列表响应成功、真实提问成功并计1次，再显式切回提供者模式。脱敏回执在`outputs/v049-review/real-personal-api-check.json`。真实API `/models`返回deepseek-flash与deepseek-v4-pro；不据此宣称两者所有功能均已测试。

UI/保存版验收与最终发布以progress及外部回执为准。自检修正重复弹窗标题ID，使用React useId；设置与对话弹窗可嵌套打开、关闭后返回原对话。已检查1280及1041无横溢/重复ID、默认接口真实工资7500与差50、20→19计数、关闭清空、错误不覆盖与嵌套返回。发现高级表单按钮首屏外，已压缩重复状态说明、把固定服务地址改为简洁文本；1280×720下全表单及主按钮无内部滚动，几何回执api-form-geometry.json。实际保存版与旧快照最终对应见发布回执。

本轮没有部署腾讯云，没有公网HTTPS实测、真实攻击压测、独立准确率或真实新人/低配验收。默认比赛接口与临时用户接口都只连DeepSeek；其他服务商和持久保存个人密钥未实现。目标90不当作已得分。

## 腾讯云后续接续（本轮仅说明，不执行）

适合支持Node 24.21+和持久私有目录的单实例部署。若使用容器/云托管，必须挂载持久目录并确认写权限；仅静态托管无法运行本机网关，临时磁盘丢失会使账号/额度失去连续性。不把多副本独立磁盘当共享配额。

1. 使用本版源码执行`npm ci`、`npm test`、`npm run build`，通过`npm start`运行Node服务。
2. 由部署平台注入`DEEPSEEK_API_KEY`、`FIRST_STEP_AI_MODEL`，不要用`VITE_*`；私有配置不上传Git。
3. 设置`FIRST_STEP_PUBLIC_ORIGIN=https://实际域名`、`FIRST_STEP_DATA_DIR=持久私有绝对路径`。本地反向代理建议Node监听127.0.0.1，HTTPS由代理处理；需要容器外部接入时显式设置HOST并核对网络边界。
4. 代理保留Host和浏览器Origin。只有代理在本机回环、覆盖`X-Real-IP`时才设`FIRST_STEP_TRUST_PROXY=loopback`，否则保持关闭。不要向公网同时开放绕过代理的Node端口。
5. 使用真实HTTPS网址检查：API Key未出现在页面/资源/返回数据；Cookie为Secure/HttpOnly；跨站POST被拒；游客A/B和登录账号隔离；异常/取消可恢复；切接口与额度不相互重置；重启后计数和主动保存资料保留。

限额可由`.env.example`中列出的`FIRST_STEP_LIMIT_*`进程环境调整，0表示停用该资源。当前限额是试用初值，要按真实体验及API成本调整；未做实际云端验收前不能标记生产就绪。

参考：[DeepSeek官方模型列表接口](https://api-docs.deepseek.com/api/list-models/)、[Node Crypto](https://nodejs.org/docs/latest-v24.x/api/crypto.html)。
