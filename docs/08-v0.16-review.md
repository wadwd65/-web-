# v0.16 · 连续事务空间 / 交付前审核

日期：2026-10-28。用户本轮已明确恢复开发，并要求每次版本提交前审核视觉与主题关系，偏离即回退。

## 本轮改变

- 从静止的白底二维阵列改为持续运行的三维事务轨道：银色切角层板、深色选中资料面、空间光线和有纵深的流动点阵。背景在填写、结果和返回过程中保持存在。
- 八个事务共用一个持续存在的场景。点击下方事务可直接进入对应界面；工作中可直接切换下一项。选择时，实体资料经真实网格采样点迁移、重组，镜头接续移动，不排队播放旧目标。
- 进入工作时，选中资料向左侧独立区域移动，右侧展开可读工作区。合同保留原文/结果、工资展开应发/扣款/实发三层金额、补贴用五个节点表达实际条件状态。后两者依赖当前会话数据，未填写不假造结果。
- 材料、结果、原文定位、清单、跨事务与返回使用连续动效。表单组件持续挂载，切换不会丢本次填写。
- 左上标志改为完整的无穷轮廓及加减符号，扩大安全边界；入场与页首复用同一个SVG组件。

## 视觉审核中撤回和修正的部分

1. 首轮仍像浅色平板、点阵太淡，没有达到本轮目标；未作为交付保存。改为明暗对比明确的深色资料面、银色结构和有空间层次的环境。
2. 工作区打开时，焦点/原文定位会使外壳滚动，页首消失。外壳改为overflow:clip，工作区保留独立滚动；实测页首top保持0。
3. 部分桌面比例下，选中资料会靠近边缘。工作状态改用真实相机投影锚点，并在桌面窄窗口减小资料比例。
4. 首轮点云过度集中在细刻线。改为合并实体网格后按表面积采样，轮廓与厚度更清楚；没有使用图片亮度推深度。
5. 修复曲线首帧参数异常；连续时间非负、路径参数循环归一化。
6. 结果视图样式曾把共享清单的标题/导出一起隐藏，已缩小选择器范围。实际下载TXT已核验。
