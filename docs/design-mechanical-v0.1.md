# 当前视觉方向：机械玻璃与科技生命

2026-10-26 用户最新反馈具有优先级：原先浅色纸张/档案风格过于平淡，要求明日方舟本体的机械感、玻璃感和科技生命感。

## 保持

- 深石墨及墨绿外壳，克制的薄荷绿/浅绿信号光。
- 半透明板材、上缘反射、双层细线、切角及少量金属高光。
- 部分明亮的主要操作模块，与暗色玻璃形成大小和明暗对比。
- 原创 2D SVG 生命核心，仅用于首页视觉；不引入复杂 3D。
- 正文有稳定阅读表面；原文输入区可以用偏亮的磨砂面，不恢复整页纸张/档案风格。
- 清楚的中文业务名称。队名主题不改变产品功能，不增加角色、剧情或玩法。
- respects prefers-reduced-motion；装饰呼吸与轨道动画不冒充模型分析。

## 代码位置

mechanical.css 是当前主题覆盖，必须在 styles.css 后导入。BioCore.tsx 是当前首页图形。App.tsx 仍留有未使用的旧 Atlas 函数，可后续清理，不要恢复使用。
