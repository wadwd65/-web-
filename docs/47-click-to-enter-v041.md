# v0.41 点击进入与流畅入场

2026-11-04。用户希望网页打开后停在入口，点击才开始，避免页面加载期间自动播放结束。参考明日方舟登录界面的主动进入节奏，沿用本项目原浅色标题和主题符号，没有增加第三方素材。

## 实际行为

1. 完整首页每次文档加载均显示“点击进入”，不因先前看过而跳过。站内返回首页不重播，工具直达和显式简易入口不新增门槛。
2. 点击主按钮或按Enter后播放。未就绪先等待，页面隐藏时暂停阶段计时；低频20Hz阶段时钟只在状态变化时更新React，CSS/Three各自负责平滑绘制。
3. 0–650ms标题响应；650ms展开原标记/任务线；1750ms唤起原三维并淡入首页；2100ms幕布开始退出；3300ms最后淡出；3750ms解除首页inert。大卡顿单次最多推进250ms，避免直接跳过整段。实际墙钟长度随卡顿延长，非硬件流畅保证。
4. “直接进入”/“跳过动画”或Escape可直接进入。重播回到等待画面，不清空当前问题或重建音频。主题音乐开关单独操作，不会误触进入。
5. 系统减少动态仍需主动点击，点击后直接进入，不强制等待长动画。此分支经生产状态机单元测试，未修改系统设置作实测。

## 根因与修正

旧版在挂载后自动设置多个定时器，不等用户操作；seen会话标记令再次打开直接跳过。三维直到覆盖层完成后才启动，视觉容易突然出现。现改为显式入口和可见时间阶段状态，并在幕布前唤起原场景。

QA首轮发现幕布打开时底部入场说明短暂叠在首页输入上，已让它和主标题同步淡出并设inert。标志始终完整，避免等待→播放时反向回描；动画后焦点回首页。阶段推进从每帧RAF改为20Hz轻量计时，避免受重场景绘制频率牵制。

## 验证

- 139项测试、TypeScript和生产构建通过；新增4项生产时钟测试覆盖无人操作/准备未就绪/隐藏/阶段先后/减少动态/跳过。原共享Three 583KB构建提示保留。
- 独立localhost:5270，仅合成材料。长时间等待仍为waiting，刷新后仍需点击；实际点击与Enter进入、回放和Escape均通过。幕布交接时首页及入场页脚均inert，三维已提前唤起；结束后唯一问题输入、单audio、无横向溢出。
- 回放后未发送问题保留；在等待页开启音乐，真实本地audio播放，退出入场后持续播放且不新增audio。QA结束清合成输入并停止音乐。
- 显式?mode=simple直接使用首页，未加载入场。完整首页结束后可能依原策略自动简易，手动切回有效；没有将此作为低配实机验收。
- 9个保留文件的LF哈希与v0.40一致：home-layout、home-overview、experience、motion-terminal、TaskArrayScene、MusicArchiveScene、music-player、Soundtrack、RhineMark。业务/API源码未重做，本轮没有重跑在线AI。
- 截图和结构证据位于outputs/v041-review；静态截图不能替代真实设备连续动画验收，用户审美反馈仍待。
