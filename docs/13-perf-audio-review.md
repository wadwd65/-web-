# v0.19 · 闪烁、性能与本地音乐审核

2026-10-29。沿用 v0.18 的银蓝八事务空间；本轮处理闪烁与性能、扩充本地音乐，并做新用户流程审核。没有另起主视觉或更改业务规则，仅电脑端。旧 v0.18 完整保留。

## 原因与修改

1. **四角深度冲突**：显示面在 z=0.155；旧四角圆柱中心 z=0.145、厚0.02、旋转后前表面恰为0.155，且位于显示面范围内。两者共面引发 z-fighting。现将紧固件移至金属边框外缘 x±2.23、y±1.59，缩小半径0.026，前表面降到0.125；与显示面留0.03的实际间距。增加粗糙度，降低尖锐反光。这是几何修复，未用周期隐藏遮掩。
2. **四段鼠标准星与全屏绘制**：旧鼠标画布每次移动后持续约650ms清空和重画整屏；按钮上绘制四段旋转弧线。现使用一个细轮廓、6个复用粒子、2个复用点击回波，只更新小元素的 transform/opacity。鼠标停止后无持续JS绘制循环，输入框、弹窗、减少动态和窗口失焦时收敛/隐藏；原生鼠标保留。
3. **细刻度大量逐个绘制**：每份资料的56条细刻度与4个紧固件改为两组 InstancedMesh，共8份；位置、材质与三维结构保留。不可见点云/轮廓不再提交绘制，真实几何采样仍来自模型本体。
4. **重复DOM写入**：标签、引线、数据属性只在值改变时更新；投影位置按1/4像素收敛。隐藏细分标签跳过投影。鼠标位置不再每次重新读取整个场景边界，按钮热点按一帧合并更新与缓存尺寸。
5. **多余后台负担**：柔和阴影从每帧更新改为最多约10Hz；场景在减少动态时按需绘制，在入场遮挡、原生目录/音乐/资料弹窗遮挡和页面隐藏时停止持续渲染。恢复后继续原场景；跨事务粒子迁移按实际时间推进。

## 同场景测量

1280×720桌面，DPR上限仍1.5，保留相同抗锯齿、点流数量、材质、环境贴图与阴影分辨率。在显式 ?perf=1 页面采集，正常页面没有诊断HUD、性能观察器或报告定时器。CPU时间是JS更新与WebGL命令提交的墙钟耗时，不是GPU硬件计时。

| 指标 | v0.18基线 | v0.19同场景 |
| --- | ---: | ---: |
| 每帧绘制调用 | 621 | 143 |
| 已上传几何资源 | 626 | 153 |
| 帧内CPU耗时P95 | 3.9 ms | 2.1 ms |
| 三维标签/状态DOM写入 | 30192 /秒 | 1331 /秒 |

绘制调用下降约77%，CPU P95下降约46%，重复写入下降约96%。动态/阴影帧的绘制调用通常143–153；首次依次高亮八个资料后，8份轮廓几何懒上传，资源数稳定在161附近，不是持续增长。

同一环境的基线本就约165渲染帧/秒，本轮没有声称整体FPS提高，也不保证所有设备固定帧率。内嵌浏览器后台/遮挡期间曾出现1FPS或暂停样本；这类样本不拿来计算前后提升。播放音乐时另取样：约147次绘制、CPU P95约1.7ms、同为165渲染帧/秒，单一音频元素，窗口2秒无长任务；只能代表本次环境与时段，不能据此断言任何设备零卡顿。

## 音乐资源和播放

从两首扩为五首，均已从官方公开试听源下载并转换为128kbps MP3。正常首播/切歌使用本地文件，失效时才请求官方在线备用元数据；暂停时选择曲目不拉取文件。一个持久HTMLAudioElement，不预载整个列表、不使用音频可视化或AudioContext；面板使用timeupdate事件，无500ms轮询。支持暂停、上/下一首、列表点选、音量、进度、单曲/列表循环。切换事务不重建播放器；工作降音、后台暂停、逐曲进度保留。
