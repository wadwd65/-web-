# v0.43 入场动态增强

2026-11-05。用户认为入场偏干，要求补动态效果并自检。

等待期间可见16个稀疏漂移光点、沿细线运动的光、缓慢斜向光带、标志呼吸和按钮底边流光。背景在鼠标移动时轻微偏移，标志位移更小，按钮位置固定。点击后原逐字、绘制、事务序列及双幕继续播放，符号增加轻微整体入位。

实现局限于ExperienceEntry及entry-sequence.css。指针移动按RAF合并写入CSS变量，没有每次移动更新React或读取布局。粒子使用CSS transform/opacity，动画固定数量。入口退出时卸载装饰、取消指针RAF并移除监听。可见性事件同步暂停CSS动画，根淡出和伪元素一并覆盖，系统减少动态及原静态模式提供关闭分支。
