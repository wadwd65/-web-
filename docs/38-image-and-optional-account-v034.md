# v0.34：单张合同图校对与可选个人空间

2026-11-02。沿36号完成单图路径；用户追加右上角可选登录与情况记忆。本轮使用现有模型、Node内置SQLite/crypto，不新增账号平台依赖、手机、曲目或新三维。浅蓝银色主体保留。

## 单图实际链路

合同工具顶部“从合同照片开始”：选择PNG/JPEG单页（≤4MB、≤2400万像素、边长≤8192）仅本页预览；点击“发送此图识别”才把该图经同源服务发DeepSeek，不带其他文件/表单/账号资料。接口仅允许内联图片，不接受外部URL；有类型/头部/尺寸/请求体、并发/频率、来源和本机Host限制，取消会中止请求。

结果呈现可编辑文字及不清楚/截断提示，没有捏造百分比置信度。先对照原图，勾选校对，再“使用校对后的文字”；此时只带入原合同文字区，主动收起图片面板并定位文字。用工类型、期限仍由用户确认，规则核对复用原实现，不自动认定法律关系或完整合同通过。TXT/MD导入和粘贴保留；PDF仍仅预览，照片不用旧文字导入入口，避免重复功能含混。

先核验[DeepSeek官方图片接口](https://api-docs.deepseek.com/guides/vision/)，再用自行制作的合成合同图真实调用。清晰图读出8000、3个月和岗位；白页实测拒绝空文字。真实UI选图→明确发送→未确认按钮禁用→确认/带入→手填类型与12/3→原规则6项/3待确认→加入清单。仅合成单页验证，不宣称复杂真实合同、多页PDF和所有模糊图已验收。

## 可选登录与记忆

- 右上角“登录 · 可选”，游客能正常用全部工具。采用与主站一致的浅色双栏弹窗、轨道线/完整符号、明确主按钮。个人空间也可收起，不打断音乐；打开时暂停后台事务三维。
- 真实账号注册/登录/退出：密码用随机salt及异步scrypt，随机会话token只进HttpOnly/SameSite=Strict cookie，数据库只存token散列与7天过期。参数化SQLite；账号/资料不接收任意userId。登录尝试和并发受限，跨来源写入拒绝。密码不在localStorage、日志或Git中。
- 保存地区、目前阶段、用户主动填写的情况备注（≤2000字）；询问清单主动保存/恢复（≤50项及请求体限制）。登录不会自动发送这些资料给模型、上传合同、同步所有表单或聊天。点“带入提问”只预填草稿，发送前可以修改。
- 账号恢复清单不覆盖游客原本的localStorage。账号下修改仅本次生效，主动保存才同步服务端；退出回原游客清单，并重置当前账号的业务填写/对话/未发草稿，避免下一人看到旧账号材料。原音乐对象保持。登录首个账号可继续当前游客任务，不自动把游客内容保存成账号资料。
- 资料存在当前服务端SQLite，默认工程外`~/.config/first-step/private-data/accounts.sqlite`；可用进程环境变量FIRST_STEP_DATA_DIR改位置。服务端重启可保留。数据库及其WAL不随源码/快照/Git；本轮QA使用独立合成账号数据库，不带到交付。部署后访问同一服务端才是同一组账号，不是已完成跨服务器云同步。

参考[Node 24 SQLite](https://nodejs.org/download/release/latest-v24.x/docs/api/sqlite.html)和[crypto](https://nodejs.org/api/crypto.html)。当前保持本机Host限制及本地HTTP会话，不称公网认证已完成。公开服务仍需HTTPS部署、可信来源配置、身份额度/滥用隔离及账号恢复。本版无邮箱、短信、第三方登录或找回密码，界面说明。

## 自检与打回

1. 发现退出账号会残留已带入的对话草稿，补账号边界重置；填写/结果与对话按账号退出重置，游客清单恢复，已保存个人资料保留。
2. 清单沿用“只保存在浏览器”旧提示，更新为游客本地/账号主动保存范围。保存清单不再覆盖尚未保存的情况备注草稿。
3. 照片与旧文件入口重复：旧入口限制TXT/MD/PDF、明确指向新图片入口。识别确认后关闭大图并定位文字。补用工类型aria-label，改善键盘/读屏定位。
4. 登录时后台三维原先仍运行，补遮盖/暂停；登录右栏可独立滚动，页首入口桌面窄窗收起非必要文字。没有更换主模型或添加重动画。

95项测试、TypeScript/生产构建通过；包括密码错误、重复账号、重启持久化、两账号资料隔离、会话撤销/过期、cookie属性、跨来源/未登录拒绝、图片类型/尺寸、未知文字、取消、错误配置。模型图片能力另有清晰图与空白图真实测试。

独立5240 UI：创建合成账号→保存广州/试用期/合成备注→刷新仍恢复；带入聊天只填草稿，退出后草稿清空。合同图识别和规则核对产3条问题；账号保存/恢复，新增一条账号专属问题保存为4项；退出游客仍3项，重新登录恢复为4项。未使用用户合同/工资/真实账号。
