# v0.33：对话续接与入口整理

日期2026-11-02。按36号计划先完成v0.33，不扩图片、RAG、音乐或手机。保留浅蓝银色三维、原模型子项保护、双模式与单audio。内部视觉检查不是用户审美验收。

## 本轮行为

- 不再按约8轮要求用户重开。请求前按原顺序保留所有已发送用户原话，只省略较早助手解释，保留最近两条助手回复的前1500字作指代背景。没有让模型摘要变成“用户已确认事实”。已确认信息、最新更正和撤回仍以原话为证。
- 服务端原有16消息/单条6000字/总24000字限制保持；客户端合并相邻用户原话满足线协议，用户材料另有约20000字容量。超限明确提示，保留记录与未发送输入，可复制现有对话后再新建。不是无限上下文或跨刷新草稿。
- 窗口“收起”保留处理，页底显示正在处理/回到对话。可以同时看工具列表，完成后回来继续。“停止”才中止，保留问题，重试不重复追加用户消息；新对话在请求中禁用，旧应用在新问题后停用。
- 同源网关可按NDJSON返回真实阶段：确认事项、执行核对、组织回复；上游仍是原有受限调用，不是虚构流式逐字输出。旧JSON调用兼容；取消、异常、超时仍传明确错误，没有假进度条。
- 首页去掉页首重复AI/工具按钮与正文重复手动入口；工作区仍保留导航，底部三入口保留。提问框/正文/补问字段对比增强。补问时主操作是填字段，自由输入折叠为用户可展开的替代方式；自动聚焦当前字段，纠正可展开自由输入。
