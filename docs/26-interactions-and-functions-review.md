# v0.28 功能、鼠标反馈与入场回放

用户要求利用剩余额度增强功能、预留API，恢复移到界面时的反馈与点击特效；随后追加入场回放。下一轮再优先解决背景仍像白膜的问题。仅电脑端。

## 已实现

1. 页首可见“重播入场”：复用原ExperienceEntry和完整序列，保留工作页面/填写/音乐；移除页底难辨认的重复入口，避免两个同名动作。
2. 鼠标覆盖普通界面、八项入口、三维、选曲弹层和完整播放器；移动有轻环/短尾，点击有650ms扩散环和四向微粒，输入区、减少动态、触摸及后台窗口抑制。修复原先依赖上一次悬停状态才能首次点击、空白区无反馈及任何dialog打开就全部禁用的问题。
3. 一个稳定portal宿主跟随原生dialog/popover，React只管理子节点，避免被top layer压住；普通页/弹层/音乐页都只有一个反馈层。六个粒子、四个点击环复用，只有鼠标移动申请一帧，动画完成即停止，不新增全屏canvas或空闲循环。弹层内宿主限制100%大小，不撑出滚动条。
4. 询问清单可手动新增八事务/其他问题，并按问题内容或事务名称搜索；原状态筛选/编辑/复制/导出/移除/撤销保留。重复、空白、超50条阻止；撤销也检查上限/重复，导出明确为全部并带事务类别。读取上限从64000提升128000字符，容纳合法的50×1500字问题及元数据。
5. 新增配置式业务API客户端、类型、同意/参数/引用校验、超时取消和说明，见25号。没有真正后端/在线业务AI，不自动调用接口。
