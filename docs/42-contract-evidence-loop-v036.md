# v0.36.0 合同核对与询问清单

2026-11-04。按36号规划完成合同原文、核对依据、询问和答复记录的关联，同时接续v0.35.2的工具页与自由对话布局。本轮仍只做桌面。

## 本轮实际改动

- 从文字、已校对的单图或AI明确应用的合同材料开始，继续复用原合同规则和八摘录官方检索。
- 每条待确认问题可附带核对项、材料名称、本次确认的合同/试用月份、核对时间、最多600字真实原文片段、字符起点和官方摘录ID。加入前可取消附带，仅保存问题。没有保存整份合同或图片。
- 清单支持改写问题、记录答复或下一步、标记状态、搜索答复、复制及导出。展开即可回查保存片段和官方依据。改写后明确标记依据仍关联原核对项。
- 同次核对重复加入不会生成重复问题，不同次材料核对分别保留。原有无来源的清单保持可用。账号主动保存和恢复保留新增关联与答复。
- 合同结果增加直接进入清单的操作。工作区收起底部重复入口，清单手动添加折叠；移除大编号，减少空白输入高度，已确认项目仍保持可读。
- 工具页保留八项简短入口与真实提问，全屏浅色对话常驻自由输入。工具页暂停隐藏三维，并排除暂停时的低帧采样。
