# v0.23 · 音乐档案构图与交互复核

2026-10-30。用户明确恢复开发，要求先审视构图，美观则保留，不美观则重新设计；保留播放旋转等已有交互。本轮是当前音乐辅助界面的构图重排，不是另起音乐业务、改变八事务方向或全站重做。

## 自检发现与主要调整

1. 旧版五张档案近似平行挤在一起，前后层次不足。改为固定的浅弧形锚点、错落高度、轻微展开角度与更靠近的总览镜头；悬停仍在这些锚点上连续抬升，不自动重排或选择。
2. 旧版背板、盘片和环境亮度过于接近。收窄边框、降低厚重双边，增加盘托圆环，统一冷银/浅蓝背板、珍珠蓝盘片、蓝色细刻度与深蓝文字；大面积黑盘、暖灰石墨色不再引入。
3. 旧版完整开盖后，其他档案仍从画面底部露出，盖板内侧空白。其他档案连续退出后才隐藏，返程提前恢复；详情仅留当前同一对象，左盖新增英文曲名、目录编号与共享主题符号，盘片位于右侧。
4. 重新分配三维空间与右侧信息宽度，压缩顶部和底部辅助信息；曲库、详情与播放栏共享细线和直接排字。去除大面积实心播放按钮，改为横向入口与圆形控制。修复旧版目录内容挤入底栏的布局问题。

没有复制参考项目的源码、CG、模型、封面或账号功能。沿用既有主题符号和五首本地音频；不新增素材授权主张。

## 交互保留与纠错

- 悬停连续高度场、邻近慢传播、单击抽取、约169.2度开盖、拖动查看、滚轮缩放、收回与前后翻阅保留。
- 播放中的盘片持续旋转，暂停保持当前角度；底部小唱片同样跟随播放状态。减少动态开关仍生效。
- 复核发现新锚点计算一度漏加非当前对象的hoverLift，导致相邻波动没有完整体现；已修复并重新观察到五张实体的高度变化。
- 首次直接进入音乐页时，进度监听可能早于父级audio引用挂载，造成音乐和旋转正常、显示仍停在0:00。改为useEffect在引用挂载后注册媒体事件；真实本地播放后时间和滑块均推进，暂停后保持。
- 单audio跨页面复用、候选档案与播放曲目分开、外部切歌进入详情、音乐与业务填写保留等结构不改。

## 验证范围

- 在1280×720桌面页面逐一直接实点五张物理档案的一个可见位置，均进入正确曲目、显示detail、约-169.2度开盖、仅一个可见档案；收回均回到五张阵列。此记录不是五模型所有像素/边缘的命中覆盖。
- 鼠标实际移入第三张实体后，阵列持续抬升，相邻对象跟随；不误展开或自动切歌。保留独立QA记录与截图。
- 实际本地A World Above播放，盘片角度变化，媒体进度约13.87秒时UI显示0:13、进度约13.8秒；暂停后两次间隔检查，时间13.92907与盘片角度-1.5326保持不变。
- 播放A World Above时浏览Control's Wishes，音频仍为CID232265且继续播放。未将浏览动作当作切歌。
- 最长曲名与开盖详情已检查，播放栏上方有独立操作空间。仅电脑端，不追加手机设计或测试。
- 既有35项规则、路由、音频与几何检查通过；最终TypeScript/Vite构建另随交付保存。共享Three.js包体提示不当作运行失败。
- 视觉复核为内部判断：相较v0.22，主体更集中、空间退出更完整、细部与排字更统一。不能代替用户审美评价，也不声称达到四个参考的所有效果。
- 未把旧v0.21的帧率数据搬作本版性能结论；本轮目标是构图和已有交互保留，不承诺所有电脑60fps。
