# v0.17 交付前审核：入场、音乐与三维交互

日期：2026-10-29。范围：用户指定的三项交互增强；保持 v0.16 银蓝空间与八事务主题，不开发手机。结论：本轮交互与主题检查通过，可供用户评审；不宣称用户审美已验收。

## 相较 v0.16 的变化

1. 沿用文字显现、完整符号、轨道和双幕入场，接续三维资料错时入位；入场可主动开启音乐。重播保留业务内容和音乐对象，事务切换不会自行重播入场。
2. 八份资料增加描边、抬升、玻璃和亮度反馈；标题直接打开对应事务。可体验模块另有材料、结果、清单入口；五项规划保持待开发标识。
3. 合同三层、工资三柱和补贴五节点分别关联原文、依据、字段、真实结果或清单。工作模型不因悬停漂移；细小部件扩展命中范围。
4. 添加官方在线主题音乐。当前及历史保存点未找到旧 BGM，用户随后授权检索主题音乐，因此没有把新实现冒充旧逻辑恢复。

## 视觉与主题

保留银、蓝、冷白的同一场景和完整左上符号；入口、模型反馈、浮动文字、播放器采用相同细线与直接排字。未引入角色、剧情、无关建筑、品牌字形雕塑或新后台卡片布局。工作内容仍是合同、工资、补贴和待开发模块。

1280×720 桌面检查首页、悬停、工作区和音乐面板后，修正了：浮动动作挤到编号、准备点击时文字移走、返回时两组说明重叠、隐藏标注短暂残留、工作上下文挡住模型、细资料层命中范围过窄。使用独立 5200 验证页，未反复操纵用户正在看的标签。

本轮深化交互，不把原有审美争议宣称为解决。截图及命中检查在参赛包 `05-验证与成果/交互增强-v0.17`。

## 官方在线音源

- [Rhine Lab.LLC / 塞壬唱片-MSR](https://monster-siren.hypergryph.com/music/779491)，默认。
- [A World Above / 塞壬唱片-MSR](https://monster-siren.hypergryph.com/music/232265)，备选。

Node 服务从官方 `/api/song/{cid}` 获取当前签名地址，只允许以上 CID 和官方 HTTPS CDN，缓存 15 分钟、超时 12 秒。浏览器直接播放官方流，无音频二进制随包，也没有搬运参考作品音频。用户手动启播；失败显示重试与来源。需要带 `tools/music-source.mjs` 接口的 Vite/Node 服务，单独双击 index.html 或纯静态托管不支持该接口。
