# v0.18 · 八项工具与鼠标交互说明

2026-10-29。用户要求在当前白膜基础上补真实功能和鼠标细节。本轮保持银蓝三维事务空间，补五项原规划入口，不另起艺术世界，也不开发手机端。八项均有本地可操作流程，在线 AI 尚未接入。

## 鼠标：触发条件和具体表现

| 出现时机 | 表现 | 约束 |
| --- | --- | --- |
| 细指针在三维背景移动 | 低密度蓝色粒子短尾，450–630ms 消散；场景点流受鼠标扰动，侧光轻微移动 | 粒子上限38；不替换原生指针，不挡点击 |
| 悬停任一资料模型 | 轮廓高亮、玻璃微抬、亮度提升；总览中主体微抬、前移和约2.5%放大 | 悬停不切事务、不自动开工作区 |
| 接近资料上方标题 | 标题展开，显示材料、结果、清单入口；细线仍指向真实模型 | 当前指向文字固定位置，其他标注避让 |
| 悬停按钮和链接 | 细弧准星跟随，按钮下划线/局部蓝光与图标轻移 | 按钮本体不追鼠标，避免点空 |
| 左键按下可操作目标/场景 | 420ms 扩散细环，按钮1px按压反馈 | 反馈只表示输入发生，不冒充核对成功 |
| 单击资料空白处 | 选择该事务并迁移真实几何点 | 不直接进入；标题文字可直接进入 |
| 双击资料或点击标题 | 进入对应事务，镜头与工作区衔接 | 拖动超过阈值不当点击处理 |
| 悬停工作态细部 | 对应条、金额柱、路线节点高亮并显示可点击文字 | 工作模型保持稳定，不因鼠标抬动；扩大细小命中区 |
| 鼠标进入输入/选择控件 | 收起操作准星，不生成跟随粒子，仅保留字段下划线与焦点 | 不影响文本选择、日期和勾选 |
| 减少动态/系统偏好/后台 | 关闭鼠标画布特效，保留直接操作与静态高亮；后台停止绘制 | 不靠播放动画才能使用功能 |

鼠标反馈由 PointerFeedback.tsx、scene-interactions.css、tool-details.css 和 TaskArrayScene.tsx 配合实现。DOM反馈层 pointer-events:none；原有滚轮、拖动、键盘和媒体播放逻辑保留。

## 八模块的作用、操作与内在逻辑

| 模块 | 作用与输入 | 可交互行为 | 内在逻辑及输出 |
| --- | --- | --- | --- |
| 01 Offer 对比 | 手填2–3份机会的月薪、明确月数、试用月薪、住房通勤、工时与签约关系 | 加减机会、改条件、切换三种比较维度、收集问题、导出 | 金额按分对齐；月薪×明确固定月数，另列12薪基准；税前年薪减12个月生活预算不叫到手。未知条件不补0，不给总评分或自动选工作 |
| 02 合同核对 | 原文、用工类型、合同与试用期限 | TXT/MD读取、其他文件预览、核对、展开发现、选中原文、查依据、整理问题、导出 | 原有本地文字规则与确认值对照，原句可定位；未定位不等于合同违法；PDF/图片未接OCR |
| 03 工资明细 | 工资条上的应发、个人扣款、实际到账 | 改金额、载入示例、展开计算、核对到账、收集问题、导出 | 以分运算，应发减个人扣款等于实发，再与自述到账比差额；不推算地方社保缴费比例 |
| 04 个税指引 | 确认居民个人及仅工资薪金等范围，填全年收入、已知扣除和预缴 | 切年度、范围确认、公式试算、点税率档位、查扣除说明、导出 | 60000元基本费用与手填扣除后按七档年度税率计算；展示逐步公式和预缴差额；不认定扣除资格，不保证退税，不覆盖其他所得及特殊税务情形 |
| 05 社保医保 | 选参保、异地就医、关系转移或卡片；自述地区与险种 | 生成四步路线、逐步勾选、备注、查官方入口、导出 | 依据情形选路线，未知地区/险种保留待确认；地方待遇、费率和报销不推断。勾选只是个人台账，不是官方办结 |
| 06 租房核对 | 粘贴租房原文，另填确认后的首次费用 | 展开七类条款、回原文选区、核对费用、收集问题、导出 | 关键词定位与重点待确认分开；首次费用=月租×首次付租月数+押金+其他首次费用，任一未知不汇总；不把已定位当合规结论 |
| 07 补贴匹配 | 当前仅广州政策样例，按学校所在地及毕业/支持/申领情况 | 条件初筛、查未知、将未确认条件放入清单、查官方入口、导出 | 保留原有规则，未知与不匹配分开；申报期、学校及材料仍需核实，可能符合不等于获批 |
| 08 离职转接 | 关系、解除方式、试用期、实际日期与去向 | 建五项交接台账、勾选、备注、导出、查依据 | 主动通知、协商、单位提出/其他情形分别处理提示；未知不套通知期限；日期是自记，不自动判定合法离职日。保障按险种另核实 |

每个工作区都有“这件事怎么做”，给出三步用法与处理边界；结果页缩短重复说明，让真实结果先出现。三维表面同步实际材料/结果摘要；工资和个税柱对应真实金额，社保与离职节点对应自记进度。不是展示随机数字。

## 共同闭环

总览 → 悬停预览 → 点击标题/事务 → 材料 → 规则/计算/路线 → 真实结果 → 原文/依据/问题 → 导出 → 返回或切换。八个模块挂载后保留本次操作状态；刷新清空本次材料和台账，只有询问清单独立保存在当前浏览器。

材料不会上传给模型或第三方。官方页面/办理链接由用户主动打开；音乐仍使用前一版的官方在线元数据与CDN，首次需手动播放。地区服务和实际受理不在本站代办。
