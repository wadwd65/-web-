## 你上线时需要的运行方式

部署仓库仍为wadwd65/-web-。使用支持Node.js 24.21.0+的服务器或托管服务，工程根目录执行npm ci、npm run build、npm start。源码、public和tools需一起部署，Node提供AI、图像、账号和静态页面。

在托管平台的环境变量面板或服务管理器配置下面值。它们由Node进程环境读取，公开域名设置不会从密钥文件自动导入。模型密钥沿用私有服务端变量，不能放进VITE变量。

```dotenv
DEEPSEEK_API_KEY=在服务器环境中填写
FIRST_STEP_AI_MODEL=deepseek-flash
FIRST_STEP_PUBLIC_ORIGIN=https://你的实际域名
FIRST_STEP_DATA_DIR=/var/lib/first-step
PORT=5186
```

同机Nginx反向代理可保持默认127.0.0.1监听。托管平台要求监听全部接口时另设FIRST_STEP_HOST=0.0.0.0，同时必须配置PUBLIC_ORIGIN。账号数据目录放持久化私有盘，网站资源目录只公开dist。

在已有HTTPS站点的server块中使用下面location，域名、证书与进程守护由部署平台配置。Host需保留实际站点及端口，Origin保持浏览器原值；关闭代理缓冲后，分阶段回复才能及时到达页面。[Nginx代理缓冲与请求头文档](https://nginx.org/en/docs/http/ngx_http_proxy_module.html)

```nginx
location / {
    proxy_pass http://127.0.0.1:5186;
    proxy_http_version 1.1;
    proxy_set_header Host $http_host;
    proxy_set_header Origin $http_origin;
    proxy_buffering off;
    proxy_read_timeout 75s;
    client_max_body_size 6m;
}
```

现有AI全局并发2、每分钟12次，图片并发1、每分钟6次，适合先邀2–3位同学体验。按用户额度分配、账号找回与大规模访问保障仍待，当前不据此宣布面向大量用户的公网运营验收。发布前实际域名依次确认首页、AI、单图校对、可选账号和音乐可用。

## 发给同学的方式

先给普通网址 https://你的域名/#/home ，不解释按钮位置，不口头引导，使用下列合成任务。每人约15分钟，记录成功/卡住、用时、求助位置和原话。不要使用个人真实工资和合同做首次体验。

|任务|只对受试者说的话|开发侧完成标准|
|---|---|---|
|合同|找一个办法看看示例劳动合同，把要问清楚的内容保存成能带走的清单|找到工具或直接提问，能理解结果范围、看原文/依据、加入并导出清单|
|中断|先填应发8000、其他扣款0，其余暂时不知道。保存进度，刷新后接着用|主动恢复原数值，未知保持空白，没有被强行按0计算|
|自由提问|先问一个入职问题，再自然换成租房问题，按自己的说法提问|能发送、更正和换题；理解哪些内容发出、结果下一步在哪操作|

低配设备单独使用 https://你的域名/?perf=1#/home 。先保持默认完整模式并操作约1分钟，如果自动简易出现就记下场景，再手动恢复完整，核对输入和音乐。最后在左下“性能记录”下载JSON，并补充设备CPU/GPU型号和浏览器。只打开简易模式时没有三维有效帧窗口，报告中的空数组表示未采样。

这些参与者结果与真实低配报告回来后再重评。11/14冻结、11/17材料、11/18提交，按每天3–4小时安排。
