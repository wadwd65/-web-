# 整体UI重做 · 八模块沉浸终端 v0.13

## 这次改了什么

从“旁边放一件三维摆件”转向“完整环境就是界面”。用原创银白研究建筑、云海与天空形成纵深，冷白金属和天空蓝延续材质方向；深蓝只用于文字背后的连续光影与底部导航，不放独立深色星空、不再搭配米白页片。主画面不放巨型产品名、书本、卡片阵列或抽象翼片。

前景只保留明确的章节标题、操作和真实业务状态，其他信息进入可随时关闭的事务目录/工作区。八项采用开放排字和细线组织，共用一个全屏环境，不把首页做成八个矩形卡片。

## 与此前银蓝版比较

参考基线为工作区 `outputs/初程-v0.5-首页-桌面.png`（1280×720）及 `outputs/初程-v0.8.1-首页-桌面.jpg`（1280×800）。以实机画面作构图与层次对照，不虚构量化审美分数，不声称已被用户认可。两张基线高度不同，不是严格同尺寸实验。

| 方面 | 此前银蓝模型版 | 新版的具体变化 |
|---|---|---|
| 画面完整性 | 主要由单个模型承载，环境较空 | 近景钢构、中景玻璃建筑、远景云海共同形成整屏空间 |
| 视觉主体 | DNA或已被否定的抽象翼片 | 没有独立摆件；画面围绕可探索环境和任务章节组织 |
| 信息组织 | 围绕三项任务，部分标签压在模型附近 | 八模块固定索引、全屏目录、工作区分层，入口不依赖三维拾取 |
| 材质与配色 | 实时玻璃、金属、银蓝配色 | 延续银蓝明暗与反射观感，但建筑材质来自原创场景图像；不声称实时材质更强 |
| 动态效果 | 模型展开/旋转 | 场景视差、27,280点图像粒子重构、局部鼠标扰动、观景/静态切换 |
| 功能一致性 | 模型与工作区语言存在割裂 | 工作区从同一环境中展开，底部八模块导航持续存在，内容隐藏后保留 |

这版在环境丰富程度、八模块扩展与内容层级上有明确增加；旧版具有真实独立模型可观察的优点，新版当前不具备建筑自由漫游。不能用“一张CG加粒子”冒充完整三维建模，也不能保证主观审美各方面都超过旧版。

## 参考与原创边界

- [RhineLabUI](https://github.com/LBEILC/RhineLabUI)：学习入场节奏、终端几何与操作反馈。本轮没有复制它的源码、模型或标志路径。
- [Rhine Music Database](https://github.com/MikeQu223/Rhine-Music-Database)：参考真实功能保持统一界面语言的思路，没有引入音乐业务或Qt代码。
- [laiyin-video](https://github.com/tmc5csxr9m-cpu/laiyin-video)：登记为几何与节奏参考；未声称看完原视频或照帧复刻。
- [rhine-lab-art](https://github.com/reverieach/rhine-lab-art)：参考场景、章节浏览与鼠标粒子共同构成体验的方式。没有搬运其CG、BGM、字体或Active Theory发布运行时，也没有声称完整研究其原始shader。

背景使用imagegen内置工具按独立提示词生成，并存入本项目；图像平面、像素采样、粒子扰动与界面均为本轮独立实现。没有新增外部图片、音乐或跟踪脚本。原图与提示词记录在 `scene-art-prompt-v0.13.md`。
