# v0.27 桌面首页：信息层级与事务入口

## 用户要求与范围

用户要求保留既有内容与功能，强化首页关键信息、功能入口和背景视觉；随后明确“移动端先别做”，本轮只做桌面。原v0.26银蓝三维阵列、跨事务动态、八业务和五曲播放器保留。没有将这个首页改成独立艺术站或普通卡片后台。

## 设计调整

- 首行直说“初入职场办事工具”，补充从签约、工资到生活衔接的用途，减少只看到合同模块就误解产品范围的问题。
- 当前事务维持大标题，主操作改成深蓝圆形箭头、明确动词及准备/继续结果提示；准备材料、能带走的结果、真实本次状态与合成示例保留。
- 八项入口由底部一行小字改为两行无框目录。每项有名称、识别图标、编号、一句用途与进入箭头；点击直接进入，不要求先理解或操作三维。补贴仍明确为广州政策样例。
- 展示“本地工具体验、填写仅本次保留”的真实使用提醒，页首资料按钮补充“使用说明”可见文字，继续打开原资料与能力说明。
- 点云、复位、减少动态、纯净观景收纳到可展开的场景设置；原操作和纯净模式返回均保留。
- 背景补充天空蓝光场、低对比空间测绘弧线、刻度与细纹理；无新增图片、外部资源或逐帧JavaScript循环。三维整体上移，为目录留出清楚的阅读区；模型、镜头与业务动画代码没有替换。
