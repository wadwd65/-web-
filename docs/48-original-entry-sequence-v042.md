# v0.42 原版序列入场优化

2026-11-05。用户明确否定v0.41，要求依据之前入场优化，并先完成视觉自检。

## 设计与实现

本轮对照v0.39原入场，将等待入口与动画演出分开。等待页以居中标志、初程名称及进入行为构成焦点，点击后再出现原“世界展开。下一程，由此开始。”文案、绘制符号和三段事务，最后通过双幕接入实际首页。

银白底与蓝灰字色服务于入场。两半幕布共享连续背景，中缝修正后不再穿过居中标志。逐字与绘制动画各自建立，绘制完成后停留约550ms。每条SVG路径使用pathLength=1，幕布退出时清除虚线配置，解决固定180路径长度造成的缺尾。

序列总时长约4.9秒，点击后900ms开始符号绘制，2700ms提前唤起三维，3100ms幕布展开，4450–4900ms淡出结束。原可见时间钟、等待实际准备、Enter、Escape、重播和独立音乐开关继续工作。

## 自检与修正

首轮截图发现中央接缝、事务序列过淡，以及绘制动画退场时重新变残缺，已修正。第二轮实查1280×720与1440×900，等待入口与底部三段事务/页脚之间有独立空间，演出标题与右侧符号之间留出间距。标志绘制中stroke偏移接近1，结束时偏移0且dasharray为none。完整播放后首页解除inert，可直接输入。

回放前的合成未发送问题完整保留，音乐经过入场仍持续播放，单audio保持。QA结束已清合成文字并暂停音频。两种桌面尺寸均无横向溢出，控制台无warn/error。独立审图确认左右视觉重量和层级可交付，最终审美反馈仍由用户提供。

139项现有测试、TypeScript及生产构建通过。4项阶段测试跟随新的时间节点更新。共享Three构建包仍约583KB。真实低配设备、新人试用与实际公网HTTPS继续等待，内部评分沿用75，85仍为目标。

本轮源码改动集中于ExperienceEntry、entry-sequence.css、entry-sequence.ts及对应时钟测试。首页/音乐原画面的9个关键文件与v0.41逐字LF哈希一致。源/包/Git对应及旧保存点保留以本轮git-publication.json为准。
